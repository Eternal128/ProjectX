# data/

Bulk data is gitignored. Each subdirectory is regenerated by a script:

| Directory | Contents | Produced by |
| --- | --- | --- |
| `raw/` | Downloaded benchmarks, never edited by hand | benchmark download script (TBD) |
| `exposure/` | Candidate matches, tiers, first-exposure steps `t0`, copy counts `n` | `src/exposure/` |
| `evals/` | Per-item, per-checkpoint results (parquet) | `python -m evals.run_checkpoint` |
| `results/` | Fitted IRT outputs and event-study estimates read by figures | `python -m irt.run`, `python -m event_study.run` |

Every parquet file carries its config hash and git commit in the file metadata
(`common.config.read_provenance`).
